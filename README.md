# 🚀 OmniKit V2

A modern collection of free browser-based tools for developers, students, creators, and everyday users.

🌐 **Live Demo:** https://getomnikit.vercel.app

---

## ✨ Features

- 🎨 Modern Glass UI
- 🌙 Dark & Light Mode
- 📱 Fully Responsive Design
- ⚡ Fast & Lightweight
- 🔒 Privacy Friendly (Browser-Based)
- 🛠️ Multiple Productivity Tools
- 🚀 Built with React + Vite

# ⚡ Getting Started

Clone the repository

```bash
git clone https://github.com/Subhashkolanu/OmniKit.git
```

Go to the project

```bash
cd OmniKit
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build

```bash
npm run build
```

A modern collection of browser-based utilities built with React, Vite and Tailwind CSS.

---

## Features

- 12 browser-based tools
- Fast and responsive UI
- No installation required
- Privacy-friendly
- Open Source
- Mobile Friendly

---

## Available Tools

- Password Generator
- Word Counter
- QR Code Generator
- JSON Formatter
- Text Case Converter
- Unit Converter
- Color Converter
- Number Base Converter
- Image Compressor
- Image Resizer
- Image Converter
- PDF Merger

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- React Router

---

## Installation

```bash
git clone https://github.com/Subhashkolanu/OmniKit.git

cd OmniKit

npm install

npm run dev
```

---

## Build

```bash
npm run build
```
